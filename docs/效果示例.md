# 实操效果示例（命中崩溃记忆）

> 演示：一次召回「之前踩过的坑/崩溃记忆」，只需一句模糊查询。

## 示例 1：召回「DSH 插件怎么装」
```bash
node src/memory_dual.js net-search --query "DSH插件怎么装"
```
输出（节选）：
```
"top": { "node_id": "71afaab61a4d", "summary": "DSH插件冷拷贝", "similarity": 0.178, "rankScore": 0.628 }
```
→ **一句话命中**之前记录的「冷拷贝三步 + 两条铁律」旗舰节点（`warning` 字段就带「禁 link 符号链接」防坑提醒）。

## 示例 2：召回「更新闪退真凶」
```bash
node src/memory_dual.js net-search --query "更新闪退" 
# 或读经验档:
node src/memory_dual.js exp-get --id EXP-19EBBC93 --env "DSH v1.1.3/Windows"
```
输出（经验档）：
```
card_id: EXP-19EBBC93   symptom: 客户端一有更新就闪退
env_lock: false          warning: 写 settings.json 必须无BOM
```
→ 直接定位到病历与解药（清 `pendingClientUpdate` + `skipClientVersion`）。

## 意义
两条轨道各司其职：**记忆网**（模糊回忆）+ **经验档**（精准排错）。AI 下次遇到同类问题，一条模糊查询即可召回此前沉淀的教训，无需重蹈覆辙。
